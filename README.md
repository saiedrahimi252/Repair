# CMMS - تجهیزات کلیدی و جایگزین

این نسخه صفحه «تجهیزات کلیدی، نیمه‌کلیدی و عادی» را به شکل جدول شبه‌اکسل ارائه می‌کند.

- اطلاعات فقط با دکمه «تکمیل خودکار» از داده‌های برنامه محاسبه/به‌روزرسانی می‌شوند.
- باز کردن صفحه یا گرفتن خروجی Excel باعث تکمیل خودکار نمی‌شود.
- هر مقداری که کاربر ویرایش و ذخیره کند به عنوان مقدار دستی ثبت می‌شود و تکمیل خودکار بعدی آن را تغییر یا پاک نمی‌کند.
- مقادیر خودکار در اجرای بعدی تکمیل خودکار دوباره از داده‌های جاری محاسبه می‌شوند.
- خروجی Excel بر اساس قالب اصلی `معیار_کلیدی_منبع.xlsx` ساخته می‌شود و قالب، سربرگ‌ها و ساختار شیت‌ها حفظ می‌شود.
- شیت «تجهیزات کلیدی بر اساس کارنامه» شامل نام، کد، تجهیزات جایگزین، کد جایگزین و پیمانکار/تامین‌کننده جایگزین است.
- سالن، انبار، ساختمان و موارد غیرماشینی وارد فهرست نمی‌شوند.

## راه‌اندازی با SQL Server

این نسخه دیگر از SQLite استفاده نمی‌کند و مستقیماً به **SQL Server** وصل
می‌شود (از طریق pyodbc). مراحل راه‌اندازی:

1. **درایور ODBC** را روی سروری که برنامه را اجرا می‌کند نصب کنید
   (`ODBC Driver 18 for SQL Server` — از سایت مایکروسافت یا مخزن سیستم‌عامل).
2. اگر هنوز داده‌ی قدیمی را وارد نکرده‌اید، فایل `repair_sqlserver.sql`
   (کنار همین برنامه قرار دارد) را روی دیتابیس مقصدتان اجرا کنید:
   ```
   sqlcmd -S <server> -d <database> -i repair_sqlserver.sql
   ```
   این فایل تمام جدول‌ها و داده‌های قبلی را می‌سازد. اگر دیتابیس را از
   صفر شروع می‌کنید، لازم نیست این فایل را اجرا کنید — خود برنامه در
   اولین اجرا جدول‌های لازم را به‌صورت خودکار می‌سازد.
3. فایل `.env.example` را کپی کنید به `.env` و مقدارهای
   `MSSQL_SERVER` / `MSSQL_DATABASE` / `MSSQL_UID` / `MSSQL_PWD`
   (یا `MSSQL_TRUSTED_CONNECTION=1` برای Windows Authentication) را
   با اطلاعات سرور خودتان پر کنید.
4. نصب پیش‌نیازها و اجرا:
   ```
   pip install -r requirements.txt
   python run_production.py
   ```

تمام منطق برنامه (app.py، auth.py، جدول‌ها و ...) دقیقاً همان چیزی
است که بود؛ فقط لایه‌ی `database.py` تغییر کرده تا به‌جای SQLite با
SQL Server کار کند (شامل ترجمه‌ی خودکار دستورهایی مثل
`INSERT OR IGNORE`، `ON CONFLICT`، `LIMIT`، `PRAGMA` و `GLOB` به
معادل T-SQL آن‌ها).
