# Handoff — وضعیت تحویل کار بین AIها

> این فایل مهم‌ترین فایل برای ادامه کار است.
> هر AI باید قبل از شروع آن را بخواند و قبل از پایان آن را به‌روزرسانی کند.

## آخرین وضعیت
هنوز وضعیت جلسه اول ثبت نشده است.

## آخرین کار انجام‌شده
- پروژه بررسی اولیه شده است.
- سیستم Context برای انتقال کار بین AIها ایجاد شده است.

## فایل‌های تغییر داده‌شده در آخرین جلسه
- `AI_CONTEXT/AI_INSTRUCTIONS.md`
- `AI_CONTEXT/PROJECT_CONTEXT.md`
- `AI_CONTEXT/CURRENT_TASK.md`
- `AI_CONTEXT/HANDOFF.md`
- `AI_CONTEXT/CHANGELOG.md`

## تست‌های انجام‌شده
- هنوز تست جدیدی در این جلسه ثبت نشده است.

## مشکل فعلی
- هنوز Task مشخصی برای تغییر کد ثبت نشده است.

## کار باقی‌مانده
1. Task واقعی کاربر را در `CURRENT_TASK.md` ثبت کن.
2. کدهای مرتبط را بررسی کن.
3. تغییر را مرحله‌ای انجام بده.
4. تست کن.
5. این فایل را با نتیجه واقعی به‌روزرسانی کن.

## قدم بعدی دقیق
Task بعدی را اینجا با یک جمله دقیق بنویس.

## نکات مهم برای AI بعدی
- قبل از تغییرات مهم، Git diff و آخرین commitها بررسی شوند.
- اطلاعات محرمانه و رمزهای SQL Server نباید وارد Repository شوند.
