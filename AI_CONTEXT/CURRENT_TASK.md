4. مدل داده SQL Server طراحی شود.

7. ارتباط داده‌های تولید با CMMS، مخصوصاً توقف و تعمیرات دستگاه، مشخص شود.
8. بعد از تأیید طراحی، پیاده‌سازی مرحله‌ای انجام شود.
