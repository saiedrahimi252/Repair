# Current Task

## هدف فعلی
افزودن وضعیت عملیاتی دستگاه به فرم «ثبت درخواست خرابی» و نمایش آن در «بررسی درخواست».

### شرح کار
- «دستگاه متوقف شده»
- «دستگاه متوقف خواهد شد»
- «دستگاه در حال کار است»
- فقط یکی قابل انتخاب باشد (Radio Button).
- انتخاب وضعیت هنگام ثبت درخواست اجباری باشد.
- ذخیره در SQL Server در جدول data.
- درخواست‌های قدیمی بدون وضعیت همچنان قابل استفاده باشند.
- نمایش در «بررسی و انجام درخواست‌ها» و صفحه تکمیل/جزئیات.
- سایر بخش‌های برنامه بدون تغییر غیرضروری باقی بمانند.

### وضعیت
- [x] کد اصلی انجام شد
- [x] مهاجرت خودکار SQL Server اضافه شد
- [x] فرم تک‌انتخابی اضافه شد
- [x] نمایش در بررسی اضافه شد
- [x] سازگاری با رکوردهای قدیمی در نظر گرفته شد
- [ ] تست اجرایی روی سرور واقعی
